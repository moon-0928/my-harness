# R2 — 목적

## 입력 (실행할 때마다 달라지는 것)

- 이번에 만들 화면 2~3개
- 아래 PRD 16절 핵심 화면 10개 중에서 고른다.
  - 홈
  - 무료 학습자료
  - 유료 멤버 자료실
  - 스킬 라이브러리
  - 미션 상세
  - 제출 화면
  - 내 학습
  - 내 자산
  - 자산 상세
  - 운영자 검수 화면

## 사용자

- 실행하는 사람도, 결과를 받는 사람도 나(디자이너) 1명이다.
- G3 내부 관계자는 하네스에 직접 들어오지 않는다. 협의 결과는 내가 대신 입력한다.

## 범위

- story-work.md 1~7단계를 모두 포함한다.
- 7단계는 임시로 design.md를 기준으로 판정한다. 가이드를 받으면 판정 기준만 바꾼다.

## 완료 기준

선택한 화면 N개가 390×844 Figma 프레임 N개로 있고,
design.md 위반 0건, 어기면 안 되는 것 A·B 위반 0건,
게이트 G1~G5 승인 기록 5개가 모두 있으면 완료다.
