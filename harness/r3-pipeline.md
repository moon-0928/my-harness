# R3 — 파이프라인

## 단계

| 단계 | 묶이는 작업 (story-work.md) | 끝의 게이트 |
|---|---|---|
| S1 리서치 | 1 레퍼런스 수집, 2 분석·반영 포인트 추출 | G1 이 정도 모으면 충분한가 |
| S2 설계 | 3 화면 설계 구체화 | G2 이 규칙(화면 설계)으로 확정해도 되나 |
| S3 컨셉 | 4 키스크린, 5 관계자 협의 | G3 컨셉 시안을 확정해도 되나 |
| S4 제작 | 6a 토큰·컴포넌트 → G4 → 6b 화면 디자인 | G5 다음 단계로 진행해도 되는가 |
| S5 검토 | 7 가이드 위반 검토 | 판정 스크립트 |

- G4는 S4 안에 있는 중간 게이트다.

## 단계별 입출력

모든 단계는 스크립트가 읽을 수 있는 md/json 파일을 1개 이상 남긴다.

| 단계 | 입력 | 출력 |
|---|---|---|
| S1 | 화면 목록 (R2) | 레퍼런스 목록 + 반영 포인트 (md), Figma 분석 보드 |
| S2 | S1 출력, prd.md, story-service.md | 화면 설계 문서 (md) |
| S3 | S2 출력, design.md | Figma 키스크린 프레임 + 컨셉 확정 기록 (md) |
| S4 | S3 출력, design.md | 토큰 (json) + 컴포넌트·화면 프레임 (Figma) + 프레임 목록 (json) |
| S5 | S4 출력, design.md | 위반 리포트 (json) |
